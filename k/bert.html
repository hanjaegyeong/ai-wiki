BERT

Bidirectional Encoder Representations from Transformers

텍스트를 양방향으로 이해하도록 학습된 트랜스포머 인코더 모델. 생성보다는 이해와 분류에 특화되어, 검색·감성분석·NER 등의 기반이 됐다.

문장을 양쪽에서 읽는다는 것

"어제 은행에 앉아 강물을 바라봤다"라는 문장에서 '은행'의 뜻은 뒤에 오는 '강물'까지 읽어야 확정된다. GPT처럼 왼쪽에서 오른쪽으로만 읽는 모델은 '은행'을 처리하는 시점에 아직 '강물'을 보지 못한 상태다. 2018년 구글이 발표한 BERT는 트랜스포머의 인코더를 사용해 문장 전체를 한꺼번에, 양방향으로 바라보도록 설계됐다. 각 단어가 자기 앞뒤의 모든 단어를 참조해 의미를 확정하기 때문에, 문장을 "이해"하는 과제에서는 같은 크기의 단방향 모델보다 훨씬 정확하다. 대신 다음 단어를 순서대로 만들어내는 구조가 아니어서 긴 글 생성에는 쓰이지 않는다. 생성은 GPT 계열, 이해는 BERT 계열이라는 분업이 여기서 나왔다. 이름의 B(Bidirectional)가 바로 이 양방향성을 가리키며, 나머지는 "트랜스포머 인코더로 만든 표현"이라는 뜻 그대로다.

빈칸 맞히기로 언어를 배운다

양방향으로 읽는 모델은 "다음 단어 예측"으로 학습시킬 수 없다. 답을 이미 보고 있기 때문이다. 그래서 BERT는 마스크드 언어 모델(MLM)이라는 방법을 쓴다. 문장에서 단어의 15%가량을 무작위로 가린 뒤 앞뒤 문맥만으로 빈칸을 복원하게 하는, 일종의 대규모 빈칸 채우기 문제집이다. 정답이 원문에 이미 있으니 사람이 라벨을 달 필요가 없고, 위키피디아와 책 코퍼스 전체가 그대로 문제집이 된다. 이 자기지도학습 방식으로 사전학습한 모델을 각자의 과제 데이터 수천 건으로 파인튜닝하는 것만으로, BERT는 발표 당시 11개 NLP 벤치마크의 기록을 갈아치웠다. "사전학습 후 파인튜닝"이라는 워크플로우를 업계 표준으로 만든 장본인이다.

LLM 시대에도 BERT가 살아남은 자리

수천억 파라미터 LLM이 등장한 지금도 BERT 계열은 은퇴하지 않았다. 오히려 눈에 안 보이는 곳에서 가장 많이 돌아가는 모델군이다. 이유는 경제성이다. 파라미터가 수억 개 수준이라 GPU 한 장, 심지어 CPU로도 밀리초 단위 응답이 나오는데, 분류·검색 같은 과제에는 그 정도면 충분하다. 실무에서 만나는 자리는 세 곳이다. 문의 메일을 부서별로 분류하거나 리뷰의 감성을 판정하는 텍스트 분류, RAG 파이프라인에서 문서를 벡터로 바꾸는 임베딩 모델(sentence-transformers 라이브러리의 기반이 대부분 BERT 계열이다), 그리고 1차 검색 결과를 질문과 하나씩 대조해 다시 정렬하는 리랭커다. 구글 검색이 쿼리 이해에 BERT를 투입한 것처럼, 모든 요청에 LLM을 부르기엔 비싸고 느린 대량 처리 구간을 BERT 계열이 담당한다.

7년 만의 세대교체, ModernBERT

원조 BERT는 512 토큰까지만 처리할 수 있고 아키텍처도 2018년 기준이라, 2024년 말 Answer.AI와 LightOn이 후계자 ModernBERT를 내놓았다. LLM 쪽에서 검증된 개선들 — RoPE 위치 인코딩, 효율적인 어텐션 패턴 — 을 인코더에 이식하고 2조 토큰(코드 포함)으로 다시 사전학습해서, 컨텍스트를 8,192 토큰으로 늘리고 속도는 2~4배 높였다. 기존 BERT를 쓰던 코드에 그대로 끼워 넣을 수 있는 호환 설계라, 분류기나 임베딩 파이프라인을 새로 짤 때 기본 선택지가 됐다. "LLM에 다 밀리지 않았나"라는 인상과 달리, 인코더 모델은 여전히 개선되고 투자되는 현역이라는 증거다.

직접 써보려면

진입 장벽은 낮다. Hugging Face transformers 라이브러리에서 사전학습된 BERT 계열 모델을 받아, 위에 분류층 하나를 얹고 자기 데이터 수천 건으로 파인튜닝하면 실용 수준의 분류기가 나온다. GPU 한 장으로 몇십 분이면 끝나는 규모라, LLM API를 반복 호출하는 것보다 훨씬 싸고 빠른데다 데이터가 외부로 나가지 않는다. 한국어라면 klue/bert-base 같은 한국어 사전학습 모델에서 출발하는 것이 정석이다. 선택 기준은 간단하다. 매 요청마다 새로운 글을 써야 하면 LLM, 정해진 보기 중 하나로 판정하거나 벡터로 바꾸는 일을 대량으로 처리해야 하면 BERT 계열이다. LLM으로 소량의 라벨을 만들어 BERT 분류기를 학습시키는 조합, 즉 비싼 모델로 싼 모델을 가르치는 패턴도 실무에서 흔히 쓰인다.
