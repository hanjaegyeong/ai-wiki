딥시크

DeepSeek

중국 AI 스타트업이 만든 오픈소스 대규모 언어 모델. Mixture of Experts 아키텍처로 GPT-4 대비 1/10 수준의 비용으로 학습하면서도 최상위 모델들과 대등한 추론 성능을 달성해, 오픈소스 LLM의 가능성을 증명했다.

왜 세계가 놀랐나

DeepSeek은 2023년 중국 항저우에서 설립된 AI 기업이 만드는 오픈소스 대규모 언어 모델 시리즈다. 2025년 초 이 이름이 전 세계 뉴스를 덮은 이유는 하나였다. GPT-4급 모델을 만드는 데 1억 달러 이상이 든다고 여겨지던 시절에, DeepSeek-V3는 약 600만 달러의 학습 비용으로 비슷한 수준의 성능을 달성했다고 발표했기 때문이다. 게다가 전체 가중치를 MIT 라이선스로 공개해서 누구나 다운받아 로컬에서 돌리거나 상업적으로 쓸 수 있게 했다. '최첨단 AI는 거대 자본만 만들 수 있다'는 통념에 금이 간 순간이었고, 미국 기술주가 출렁일 정도의 파장을 낳았다. 학습 비용 집계 방식을 두고 논쟁이 있긴 했지만, 오픈 모델의 수준을 한 단계 끌어올렸다는 평가는 논쟁의 여지가 없었다.

싸게 만드는 기술들

비용 절감의 핵심은 Mixture of Experts(MoE) 구조다. 6,710억 개의 전체 파라미터 중 토큰 하나를 처리할 때는 370억 개만 활성화해서, 거대한 모델의 지식을 유지하면서 계산량은 중형 모델 수준으로 억누른다. 여기에 Multi-head Latent Attention(MLA)으로 추론 시 메모리를 잡아먹는 KV 캐시를 대폭 압축했고, 강화학습에서는 별도의 가치 평가 모델 없이 학습하는 GRPO로 GPU 자원을 아꼈다. 2025년 말 나온 V3.2는 DeepSeek Sparse Attention(DSA)이라는 희소 어텐션을 도입해 긴 문맥 처리 비용을 다시 한 번 크게 낮췄다. 매 세대 '어떻게 하면 덜 계산하고 같은 결과를 낼까'를 파고드는 게 이 팀의 일관된 스타일인데, 미국의 수출 규제로 최신 GPU를 마음껏 쓸 수 없는 환경이 오히려 이런 효율 집착을 낳았다는 해석도 많다.

R1과 추론 모델의 충격

2025년 1월 발표된 DeepSeek-R1은 OpenAI o1에 대응하는 추론 모델이다. 흥미로운 건 실험 모델인 R1-Zero인데, 정답이 있는 문제에 강화학습만 적용했더니 사람이 시범을 보여주지 않았는데도 모델이 스스로 사고의 사슬(Chain-of-Thought)을 길게 발전시켰다. '추론 능력은 비싼 인간 데이터 없이도 길러질 수 있다'는 걸 보여준 사례로, 이후 업계의 추론 모델 학습 방식에 큰 영향을 줬다. R1의 사고 과정을 작은 모델에 옮겨 담은 증류(distillation) 버전들도 함께 공개돼서, 노트북에서 돌아가는 수 기가바이트짜리 모델로도 제법 긴 추론을 흉내 낼 수 있게 됐다. 발표 직후 DeepSeek 앱이 미국 앱스토어 1위에 오르고 엔비디아 주가가 하루 만에 급락했을 만큼, 이 릴리스는 기술 발표를 넘어 하나의 사건이었다.

지금은 어디까지 왔나

2026년 4월 공개된 DeepSeek-V4는 100만 토큰 컨텍스트를 내세운다. 압축 기반의 하이브리드 어텐션 구조로, 100만 토큰 상황에서 V3.2 대비 추론 연산을 4분의 1 수준으로 줄였다고 발표됐다. 대형 V4-Pro와 경량 V4-Flash 두 갈래로 나뉘며 역시 MIT 라이선스로 가중치가 공개됐다. 코드베이스 전체나 책 여러 권 분량을 한 번에 넣는 작업이 '기술적으로 가능하다'를 넘어 '가격표를 보고 실제로 해볼 만하다'가 된 것, 즉 오픈 모델 진영에서 긴 문맥을 실제로 쓸 수 있는 가격을 만든 게 이번 세대의 포인트다.

직접 써볼 때

가장 간단한 방법은 API 호출이다. DeepSeek API는 OpenAI 호환 형식이라 기존 코드에서 base_url과 API 키만 바꾸면 바로 전환되고, 가격이 훨씬 저렴해서 비용에 민감한 프로젝트의 드롭인 교체로 많이 쓰인다. 로컬 실행도 강점이다. Ollama에서 ollama run deepseek-r1 한 줄이면 증류된 경량 버전이 돌아가서, 데이터를 외부로 보낼 수 없는 환경에서 특히 유용하다. 다만 중국 기업이라는 점에서 API 사용 시 데이터 프라이버시와 특정 주제에 대한 검열 우려가 있어, 민감한 데이터라면 로컬 가중치 실행이 안전하다. 한국어 성능은 영어·중국어보다 떨어질 수 있다는 점, 그리고 오픈 가중치를 직접 서빙하려면 최상위 모델 기준으로는 여전히 상당한 GPU가 필요해서 실제로는 증류 버전이나 클라우드 호스팅 업체를 거치는 경우가 많다는 점도 감안할 것.
